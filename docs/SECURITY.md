# Security Policy

## Scope
This policy applies **only** to the repack scripts, documentation, and parent-level configuration.

For core-engine vulnerabilities, module vulnerabilities, or database exploits, please report them to the appropriate upstream maintainers (AzerothCore or module owners).

## Reporting a Vulnerability
If you discover a security vulnerability within the repack wrapper, please report it to the maintainers privately.

Do **not** publicly disclose the exploit or vulnerability until a fix has been released.
