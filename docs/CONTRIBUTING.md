# Contributing

Contributions are welcome!

## Scope
Acceptable contributions at this parent level include:
- Documentation updates
- Repack convenience commands and packaging UX
- Troubleshooting guides
- Module inventory updates
- Repack configuration guidance

**Out of Scope:**
- Any core engine or module source changes must be proposed and reviewed separately in their respective upstream repositories or in a dedicated core pull request, not as part of the repack layer.

## Requirements
- **No Secrets:** Do not include any credentials, passwords, or secrets.
- **No Game Data:** Do not include proprietary game-client data or DBC/map files.
- **No Player Data:** Do not include database dumps containing real player data.
- **Documentation:** Documentation must be updated when behavior changes.
